# 本地市场风险引擎：计算口径与配置说明

本文档是 VaR / ES 结果的**权威口径定义**，用于复现：相同的行情、持仓与
配置在任何时间、任何进程中计算结果完全一致（确定性，无随机数、无插值）。

## 1. 输入与符号

- 持仓：组合 `p` 中对标的 `i` 的数量 `q_i`（正多头、负空头）。
- 行情：标的 `i` 在交易日 `t` 的收盘价 `P_i(t)`，必须为**正数**。
- 窗口参数 `W`：使用最近 `W` 个**价格点**，构造 `N = W - 1` 个相邻日
  损益情景。多标的组合按**共同交易日**（inner join）对齐。
- 置信水平 `c`（开区间 `(0,1)`），尾概率 `α = 1 - c`。
- 持有期 `h`（>=1 的整数交易日）。

## 2. 历史情景损益（损失为正）

对相邻两交易日 `t-1 → t`，标的 `i` 使用**简单收益率**

```
r_i(t) = P_i(t) / P_i(t-1) - 1
```

组合在该情景下的盯市损益（用前一日市值计损益）：

```
pnl(t) = - Σ_i  q_i · P_i(t-1) · r_i(t)
```

`pnl > 0` 表示亏损。由此得到时间升序的 `N` 个情景
`{x_1, …, x_N}`（`x_N` 最新）。

### 2.1 两种口径

- **ROLLING（等权滚动窗口）**：`w_k = 1/N`。
- **DECAYED（指数衰减加权）**：按情景年龄加权

  ```
  w_raw(age) = (1 - λ) · λ^age,   age = 0 为最新情景
  ```

  权重在窗口内归一化：`w_k = w_raw(age_k) / Σ_j w_raw(age_j)`。
  `λ ∈ (0,1)`；越新的情景权重越高。

两种口径都只取窗口内最近 `W-1` 个情景；窗口外数据不参与计算。

## 3. VaR 与 ES（经验分布，不做线性插值）

将情景按损益从小到大排序（损失从大到小的反面：最小者最先遍历），累计
权重

```
C_k = Σ_{m ≤ k} w_(m)   （_(m) 表示第 m 个最坏方向的情景）
```

- **VaR**：找到最小的秩 `k*` 使得 `C_{k*} > α`（严格大于）；则
  `VaR = max(0, x_{k*})`。
  - 当 `α` 恰好落在等权样本的累计权重上（如 4 个样本、`c=0.75` 时
    `α=0.25` 恰好等于第 1 个样本权重），分界点为**下一个**情景，即该
    分位样本自身作为阈值。
  - 选择「经验分位、不插值」是为了保证结果**必为某个真实历史情景**、
    跨实现可逐位复现。
- **ES（预期缺口）**：分界点及其后更坏情景的条件加权平均，权重在尾部内
  重新归一化：

  ```
  ES = ( Σ_{m ≥ k*} w_(m) · x_(m) ) / ( Σ_{m ≥ k*} w_(m) )
  ```

  同样截断为非负：`ES := max(0, ES)`。因此恒有 `ES ≥ VaR`。
- 若最坏情景仍是净盈利，VaR/ES 均为 0（历史窗口内该置信水平下无亏损
  证据），这是正确结果而非异常。

## 4. 持有期缩放

在日收益独立同分布（i.i.d.）、波动率随根号时间缩放的标准近似下：

```
VaR_h = VaR_1 · √h,    ES_h = ES_1 · √h
```

## 5. 一个可手工复核的算例

价格 `100 → 110 → 99`，持有 1 单位多头：

- 情景损失：`x = [-10, +11]`（先盈利 10，后亏损 11）。
- 等权 `(0.5, 0.5)`：
  - `c=0.99, α=.01`：`C_1=0.5 > .01`，分界 `x_1=-10`，VaR=0；
    ES=`(-10+11)/2=0.5`，截断后为 `0`（本例 `ES=0.5` 被盈利拉低）。
  - `c=0.5, α=.5`：`C_1=0.5` 不严格大于，分界 `x_2=11`，VaR=ES=11。
- 持有期 `h=4`：结果再乘 `√4 = 2`。

## 6. 异常输入处理规则（全有或全无）

| 情况 | 处理 | 错误码 |
|---|---|---|
| 空批次 | 拒绝 | `EMPTY_HISTORY` |
| 价格缺失 / NaN / ±Inf | 整批拒绝 | `MISSING_PRICE` |
| 价格 ≤ 0 | 整批拒绝 | `NON_POSITIVE_PRICE` |
| `(标的, 日期)` 重复（批内/跨批） | 整批拒绝 | `DUPLICATE_OBSERVATION` |
| 观测日期晚于批次 `as_of` | 整批拒绝 | `LATE_OBSERVATION` |
| 向已提交序列补录更早日（迟到补录） | 整批拒绝 | `OUT_OF_ORDER` |
| 批次内日期乱序 | **自动修正**：按 `(标的,日期)` 升序排序后入库 | — |
| 共同交易日价格点 < 2 | 任务失败 | `INSUFFICIENT_HISTORY` |
| 持仓引用无行情标的 | 任务失败 | `UNKNOWN_INSTRUMENT` |
| 空组合 / 数量为 0 / 数量非有限 | 拒绝 | `EMPTY_PORTFOLIO` / `INVALID_PARAMETER` |

关键原则：**任一观测非法则整批拒绝**，不写入、不改版本、不产生任何
部分结果；数据版本 `data_version` 仅在成功提交后单调递增。

## 7. 配置版本隔离与增量一致性

- `data_version`：每成功提交一批行情 +1。
- `config_version`：由
  `confidence | horizon | method | window | decay_lambda` 派生
  （ROLLING 与 DECAYED 使用不同前缀）。
- 结果键 = `(portfolio_id, data_version, config_version)`。窗口边界或
  权重配置任何变化都会得到**新键**，已缓存结果绝不与旧配置混用；旧
  版本结果仍然可读且不可变。
- 增量更新只对各标的序列做尾部合并；窗口外旧数据自然淘汰。因此**分多批
  增量提交与一次性全量提交在相同版本/配置下逐位一致**（见
  `tests/test_incremental.py`）。

## 8. 并发与取消

- 有界线程池，并发度 `max_concurrency`（默认 4，必须 >=1）。
- 每个任务独立 Future + 协作式取消令牌；同一数据集多个任务互不干扰。
- 终态（COMMITTED / FAILED / CANCELLED）只落一次；已提交任务不可取消；
  取消中的任务不会写出结果文件。
- 查询超时只影响等待方，任务继续在后台完成，之后可再次读取完整结果。
- 结果文件采用 `tmp + fsync + 原子 rename`，外部永远只能读到完整版本。

## 9. 崩溃恢复

- `results/<task_id>.json` 存在即「已提交」的权威标志；
  结果文件已落地但 COMMITTED 日志缺失时，重启自动补登（幂等），不重复
  计算提交。
- WAL 中末态为 PENDING/RUNNING 且无结果文件的任务，重启后状态可区分，
  由 `recover()` 重新入队，不丢任务。
- 任务 id 由结果键确定性派生，重放得到相同 id，保证恢复不重复提交。
- WAL 末尾可能存在未 fsync 的撕裂半行，重放在该点停止（此前均为已确认
  事件）。

## 10. 有界资源

- **内存**：每个标的的价格序列长度硬上限为 `max_history_days`
  （默认 10000），超出后最旧数据被淘汰；窗口计算只取最近 `W` 个价格点，
  不扫描全历史。因此长期运行内存不随观测总量增长。
- **持久化**：
  - 任务 WAL 事件数超过阈值（10000）时自动 **checkpoint**，压缩为每个
    任务一条最新状态（原子重写），行数有界于「阈值 + 任务数」。
  - 行情增量批次日志超过阈值（1000 批）时自动写**市场快照**
    `market.snapshot.json`（原子 rename，仅含当前受 cap 约束的序列），
    随后截断增量日志；重启时「快照 + 其后增量」重建，版本号精确恢复。
  - 结果文件每个任务一个，数量随任务数线性增长，单文件即完整结果。
- **并发**：有界线程池 `max_concurrency`（默认 4，>=1），活跃工作线程数
  不会超过配置值。

## 11. 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `confidence` | `0.99` | 置信水平，开区间 (0,1) |
| `horizon` | `1` | 持有期（交易日），按 √h 缩放 |
| `method` | `ROLLING` | `ROLLING` / `DECAYED` |
| `window` | `250` | 窗口价格点数（>=2），情景数为 window-1 |
| `decay_lambda` | `0.99` | 衰减因子，开区间 (0,1)，仅 DECAYED |
| `max_concurrency` | `4` | 并发工作线程数（构造参数/`RISK_MAX_CONCURRENCY`） |
| `max_history_days` | `10000` | 每标的保留的最大价格点数（有界内存，淘汰最旧） |
| `query_timeout` | `30s` | 默认查询等待超时 |
| 数据目录 | `./.risk-data` | 构造参数 / 环境变量 `RISK_STORE` |
